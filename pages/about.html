О проекте

AKD Image – бесплатный браузерный сервис для повседневной работы с изображениями. Здесь можно узнать, как он устроен и какие технологии использует.

AKD Image создан AKDworks как набор практичных инструментов для обработки статичных изображений и анимированных GIF. Проект работает без регистрации и стремится оставить важное на устройстве пользователя: файлы, настройки и сам процесс обработки.

Что делает сервис

AKD Image объединяет популярные задачи в одном интерфейсе: сжатие, изменение размера, конвертацию, обрезку, эффекты, удаление фона, подготовку PDF и favicon, работу с GIF, разметку изображений и другие операции. В зависимости от инструмента можно обрабатывать один файл или целую подборку и скачивать результат отдельными файлами либо ZIP-архивом.

Как обрабатываются изображения

После выбора, перетаскивания или вставки изображения из буфера браузер читает файл локально. Для большинства операций AKD Image создает временное изображение в памяти вкладки, применяет нужные изменения через Canvas API и формирует итоговый файл как Blob. SVG перед редактированием безопасно растрируется, а HEIC и HEIF декодируются локальным WebAssembly-модулем. Готовый файл скачивается напрямую в браузере.

GIF-анимации обрабатываются покадрово: сохраняются порядок кадров, длительность и параметры повторения. При закрытии вкладки выбранные изображения и промежуточные данные исчезают из ее оперативной памяти.

При удалении фона изображение также обрабатывается локально через AKD Vision. При первом запуске браузер загружает AI-модель и среду выполнения, сохраняет их в кэше и затем применяет модель к изображению на устройстве.

Конфиденциальность и хранение данных

В проекте нет собственного backend-сервера, базы данных или облачного хранилища для пользовательских изображений. AKD Image не получает и не сохраняет файлы, которые вы добавляете для обработки.

В браузере могут храниться только настройки интерфейса, например выбранные язык и тема, а также сохраненные вами HTTPS-ссылки на логотипы для водяных знаков. Подробные условия описаны в политике конфиденциальности.

Технологии проекта

Интерфейс построен на HTML, CSS и JavaScript без тяжелого клиентского фреймворка. В основе обработки лежат стандартные возможности современных браузеров: File API, FileReader, Canvas API, Blob, Object URL, Drag and Drop API, Clipboard API и localStorage.

Для крупных задач AKD Image использует Web Workers, OffscreenCanvas, WebGPU и WebAssembly, если браузер их поддерживает. Это помогает выполнять обработку в фоне и сохранять отзывчивость интерфейса. Если отдельные возможности недоступны, сервис использует совместимый запасной вариант.

Библиотеки и компоненты

Основные сторонние зависимости находятся в репозитории. Для удаления фона AI-модель и часть среды выполнения загружаются при первом запуске инструмента и сохраняются в кэше браузера:

  • JSZip – создание ZIP-архивов с результатами пакетной обработки;
  • jsPDF – формирование PDF из изображений;
  • modern-gif – чтение, покадровая обработка и кодирование GIF-анимаций, включая работу через Worker;
  • ffmpeg.wasm – локальное преобразование видео MP4/WebM в GIF и GIF-анимаций в MP4/WebM;
  • AVIF encoder – создание изображений в формате AVIF;
  • libheif – чтение и создание контейнеров HEIC/HEIF;
  • libde265 – декодирование HEVC-изображений внутри HEIC/HEIF;
  • Kvazaar – кодирование HEVC для экспорта HEIC без зависимости от x265;
  • AKD Vision – локальная AI-обработка изображения и удаление фона;
  • Transformers.js и ONNX Runtime Web – запуск модели BiRefNet Lite через WebGPU или WebAssembly;
  • Inter – локально подключенный шрифт интерфейса.

Лицензии сторонних компонентов находятся рядом с соответствующими файлами в каталоге js/vendor и применяются только к этим компонентам. Сводка с авторами, официальными источниками и полными текстами доступна на странице «Лицензии и компоненты».

Совместимость и ограничения

AKD Image рассчитан на актуальные версии Chrome, Edge, Firefox и Safari. Скорость обработки зависит от мощности устройства, свободной памяти, размера изображения и количества кадров GIF. HEIC/HEIF, преобразование видео и AI-удаление фона требуют больше памяти, поэтому для них действуют отдельные лимиты. При удалении фона предпочтительно используется WebGPU, а при его недоступности – WebAssembly. Экспорт HEIC сохраняет один обычный 8-битный кадр без Live Photos, HDR, карт глубины и исходных метаданных.
